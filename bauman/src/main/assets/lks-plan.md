# План-график ЛКС (личный кабинет студента) — семестр 1

Источник: скриншот «Текущая успеваемость» из ЛКС, снят 14.09.2026 (неделя 3, числитель).
Показывает полную сетку по неделям 1–17 для всех предметов: когда выдаётся (ДЗ),
когда рубежный контроль (РК), когда модуль/защита (М), контрольная работа (КР).

Обозначения в ЛКС:
- **○** Выдано — незакрашенный кружок
- **◎** Выполнено раньше срока — кружок с точкой (зелёный на скрине)
- **●** Защищено вовремя — закрашенный кружок (белый на скрине)
- Оранжевый текст/обводка = «с опозданием»
- Красная ячейка = что-то просрочено/горит (на скрине: ФКиС, неделя 10, «М 8»)

На момент скрина статус «выполнено раньше срока» (зелёный кружок) стоит только у:
- Начертательная геометрия, ДЗ, неделя 5
- Химия, ДЗ, неделя 5

Это разошлось со статусом в реальности на 13.09 (черновик начерталки зачтён, но
чистовик ещё не сдан) — ЛКС явно показывает плановую сетку недель, а не всегда
актуальный статус выполнения. Использовать этот файл как график **дат**, а не как
источник правды по факту сдачи (для факта — `deadlines.md` и `brs.md`).

## Как используется

Скрипт `scripts/build_now.py` читает таблицу выше: `NOW.md` показывает контрольные точки этой и следующей
недели, `calendar.md` — все. Шапку таблицы (`| Предмет | 4 | 5 | … |`) и названия предметов не менять.
По факту сетка сходится: РК1 по информатике был на неделе 4, «РК» по истории — тоже на неделе 4.

## Не сходится — проверить

- **ФКиС:** единственная красная ячейка на всей сетке — неделя 10, «М 8». Уточнить у преподавателя.
- **Химия:** по сетке М1 на неделе 6, а по плану занятий контроль М1 — 13.10 (неделя 7). Сверить.
