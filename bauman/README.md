# Бауманка

Карманное расписание для ИУ3-13Б: пары, числитель/знаменатель, сроки, контрольные и баллы БРС.
Данные берутся из приватного репозитория `bmstu-study`, который ведёт Claude, так что приложение
всегда показывает то же, что `NOW.md`.

## Экраны

- **Сегодня** — числитель или знаменатель, номер недели, какая пара идёт и сколько осталось,
  пары дня с «окнами», сроки на 7 дней (просроченные отдельно) и контрольные недели по сетке ЛКС.
  Когда пары кончились, показывает следующий учебный день.
- **Неделя** — вся неделя по дням с переключением ‹ ›, сроки прямо под днём сдачи.
- **Сроки** — срок прошёл / впереди / ждём результат / без срока. Нажатие раскрывает темы и статус.
- **Баллы** — по предметам: сколько набрано из оценённого, риска порога, сколько не хватает.

Потяни экран вниз, чтобы обновить.

## Уведомления и виджет

- За 15 минут до пары и пока она идёт — тихое уведомление на экране блокировки: предмет,
  аудитория, обратный отсчёт.
- Сроки — накануне в 20:00 и в день сдачи (за 2 часа, если известно время).
- Виджет «Пары и сроки» 4×2: неделя, текущая или следующая пара, ближайший срок.

На Huawei/Honor: Настройки → Батарея → Запуск приложений → Бауманка → вручную, все три пункта включены.

## Подключение к bmstu-study

Расписание встроено в APK. Для сроков и баллов нужен токен GitHub только на чтение:

1. github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens**.
2. Repository access → Only select repositories → `bmstu-study`.
3. Permissions → Repository → **Contents: Read-only**.
4. Вставить в приложении: шестерёнка на главном экране.

Приложение читает `university/schedule.md`, `deadlines.md`, `rk-dates.md`, `brs.md`, `lks-plan.md`
через GitHub API раз в 6 часов и при открытии. Разбор повторяет `scripts/build_now.py`, поэтому шапки
таблиц в этих файлах менять нельзя (это и так правило репозитория).

## Сборка

Отдельный Gradle-проект, корневая сборка YT Фон его не трогает:

```
./gradlew -p bauman testDebugUnitTest assembleDebug
```

APK собирает GitHub Actions (`.github/workflows/bauman.yml`) при изменениях в `bauman/`:
**Releases → «Бауманка (сборка N)» → `Baumanka.apk`**. Подписан тем же debug-ключом, что YT Фон,
новые сборки ставятся поверх.
