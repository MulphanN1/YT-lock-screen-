# YT Фон

Android-приложение, в котором YouTube продолжает играть музыку при выключенном экране.
Включается одной большой кнопкой, как в VPN-приложениях.

## Как пользоваться

1. Откройте приложение: внутри обычный мобильный YouTube (m.youtube.com).
2. Включите видео или музыку. Сразу появится плеер, как у Spotify, в уведомлениях и на
   экране блокировки: обложка, название, канал, предыдущий / пауза / следующий.
   На Huawei/Honor плеер нарисован своим макетом, чтобы кнопки были видны без раскрытия.
   В карточку Huawei «Media Controller» сторонние плееры не попадают: там только
   приложения из списка Huawei (Spotify, Huawei Music).
3. Круглая кнопка питания вверху (красная = включено) отвечает за то, чтобы музыка
   продолжала играть при выключенном экране и в фоне. По умолчанию включена.
4. «×» в плеере ставит на паузу и убирает уведомление; оно вернётся при следующем запуске видео.

Ссылки на YouTube можно открывать сразу в приложении: «Поделиться» → **YT Фон**.

## Настройки (шестерёнка вверху)

- **Подсветка вокруг видео** — размытое свечение цветов кадра над плеером и под ним, как
  ambient mode в браузере; шапка приложения тоже подкрашивается. Только в тёмной теме; когда
  приложение свёрнуто, подсветка не считается.
- **Экономия в фоне** — при выключенном экране или свёрнутом приложении следующие треки идут в
  минимальном качестве: меньше трафика и батареи, звук тот же. Текущий трек доигрывает как есть:
  смена качества посреди трека на секунду останавливает звук. При возврате качество
  восстанавливается.
- **Продолжать с места остановки** — при запуске открывается последний трек с той же секунды.
- **Пропускать лишнее (SponsorBlock)** — по общей базе [SponsorBlock](https://sponsor.ajay.app)
  перематывает разговоры в клипах, рекламу спонсоров, «подпишитесь» и т. п. (что именно —
  выбирается). На сервер уходит только 4 символа хэша ID видео.
- **Блокировать рекламу** — баннеры скрываются, рекламные ролики перематываются без звука.
- **Виджет на главный экран** — плеер с обложкой и кнопками на рабочем столе.
- **Плитка в шторку** — переключатель фонового режима в быстрых настройках, как у VPN.

## Оптимизация

- Страница сама сообщает о состоянии плеера; резервный опрос из Android включается, только
  если эти сообщения перестали приходить.
- Если музыка стоит на паузе, а приложение свёрнуто дольше минуты, страница YouTube
  «засыпает» (таймеры JavaScript останавливаются) и просыпается от любой кнопки плеера.
- Wake lock и Wi-Fi lock держатся только пока музыка играет.
- Процесс страницы помечен как важный, чтобы система не выгружала его первым; если он
  всё-таки упал, приложение пересоздаёт страницу и продолжает трек, а не вылетает.
- Когда система сообщает, что памяти мало, приложение сохраняет позицию, чистит кэш страницы
  и на следующем треке открывает его в свежей странице (если памяти совсем мало — сразу, с той же
  секунды): страница YouTube за часы автовоспроизведения разрастается, и без этого Android
  в какой-то момент убивает приложение целиком. В фоне страница обновляется и сама, раз в 15 треков.
- В фоне не загружаются картинки (превью рекомендаций): их всё равно никто не видит.
  При возврате в приложение они догружаются.

## Установка

APK собирается автоматически в GitHub Actions:

**Releases** → последняя сборка → `YT-Fon.apk`
(https://github.com/MulphanN1/YT-lock-screen-/releases/latest). Сборки из `main` становятся
последним релизом, сборки из других веток публикуются как тестовые (pre-release).

На телефоне разрешите установку из неизвестных источников для браузера/файлового менеджера.
Все сборки подписаны одним ключом, поэтому новая версия ставится поверх старой.

## Если музыка всё равно останавливается

Некоторые прошивки агрессивно экономят батарею.

- **Huawei / Honor:** Настройки → Батарея → Запуск приложений → YT Фон → выключите
  «Автоматическое управление» и включите все три пункта (автозапуск, косвенный запуск,
  работа в фоне).
- **Xiaomi:** Настройки → Приложения → YT Фон → Контроль активности → «Нет ограничений»,
  и включите «Автозапуск».
- **Samsung:** Настройки → Приложения → YT Фон → Батарея → «Без ограничений».

Если плеер не появляется в уведомлениях — проверьте, что уведомления для YT Фон разрешены.

## Как это работает

- `BackgroundWebView` сообщает системе, что окно видимо, даже когда экран выключен,
  поэтому Chromium не ставит видео на паузу.
- Скрипт на странице подменяет `document.hidden`/`visibilityState` и глушит
  `visibilitychange`, чтобы сам YouTube не останавливал воспроизведение.
- Скрипт страницы раз в пару секунд и на каждое событие плеера сообщает приложению
  состояние: играет ли, название, канал, обложку, позицию и длительность.
- `PlaybackService` — foreground-сервис типа `mediaPlayback` с `MediaSession`: показывает
  плеер в уведомлениях, на экране блокировки и в медиа-карточке, держит wake lock и
  Wi-Fi lock, пока музыка играет.

## Сборка вручную

```
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
./gradlew bundleRelease     # app/build/outputs/bundle/release/app-release.aab
```

Нужны JDK 17 и Android SDK 35. Release-сборка сжимается R8 (код и неиспользуемые ресурсы).

## Ключ подписи для магазинов

Без своего ключа release-APK подписывается публичным `app/debug.keystore` из репозитория —
для магазинов так нельзя: любой может подписать им «обновление». Создайте свой ключ один раз
и храните его копию отдельно — без него приложение в магазине больше не обновить:

```
keytool -genkeypair -v -keystore release.jks -alias ytfon -keyalg RSA -keysize 4096 -validity 36500
```

- **Локально:** положите `release.jks` в корень проекта и создайте рядом `keystore.properties`
  (оба файла в `.gitignore`):
  ```
  storeFile=release.jks
  storePassword=...
  keyAlias=ytfon
  keyPassword=...
  ```
- **В GitHub Actions:** Settings → Secrets and variables → Actions → добавьте
  `RELEASE_KEYSTORE_BASE64` (вывод `base64 -w0 release.jks`), `RELEASE_STORE_PASSWORD`,
  `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`.

После смены ключа уже установленную версию придётся один раз удалить: Android не ставит
APK с другой подписью поверх старого.

Политика конфиденциальности для страницы в магазине: [PRIVACY.md](PRIVACY.md).
