# YT Фон

Android-приложение, в котором YouTube продолжает играть музыку при выключенном экране.
Включается одной большой кнопкой, как в VPN-приложениях.

В приложении два режима.

## 1. Встроенный YouTube (кнопка питания)

1. Откройте приложение: внутри обычный мобильный YouTube (m.youtube.com).
2. Нажмите круглую кнопку питания вверху. Она станет красной, начнёт «пульсировать»,
   и появится уведомление «YouTube в фоне».
3. Включите музыку и выключайте экран кнопкой питания: звук продолжит играть.
4. На экране блокировки: предыдущий / пауза / следующий трек и «Выключить».
5. Чип «Без рекламы» блокирует рекламу (баннеры, рекламные ролики перематываются без звука).
   Если YouTube начнёт работать странно — снимите галочку.

Ссылки на YouTube можно открывать сразу в приложении: «Поделиться» → **YT Фон**.

## 2. Чёрный экран для настоящего приложения YouTube

Настоящий YouTube без Premium ставит видео на паузу, когда экран выключается, и другое
приложение это запретить не может. Поэтому экран «выключается» понарошку: поверх YouTube
ложится полностью чёрное окно, касания блокируются, а YouTube продолжает играть.

1. Чип «Чёрный экран для YouTube» → «Разрешить» (показ поверх других окон) — один раз.
2. Включите видео в приложении YouTube, опустите шторку, нажмите плитку **«Чёрный экран»**
   и закройте шторку. Или в приложении: «Открыть YouTube и затемнить через 10 с».
3. Выход: удерживайте палец на экране 2 секунды или «Выключить» в уведомлении.

Важно: не нажимайте кнопку питания — при настоящем выключении экрана YouTube встанет на паузу.
На OLED/AMOLED-экранах чёрный цвет почти не тратит батарею; на LCD подсветка остаётся
включённой (приложение пытается убавить яркость до минимума).

## Плитки в шторке

Чип «Плитки в шторку» добавляет две плитки, как у VPN: **«YT Фон»** (режим 1) и
**«Чёрный экран»** (режим 2). На Android 12 и ниже добавьте их вручную: шторка →
карандаш («Изменить») → перетащите плитки.

## Установка

APK собирается автоматически в GitHub Actions:

**Releases** → последняя сборка → `YT-Fon.apk`
(https://github.com/MulphanN1/YT-lock-screen-/releases/latest). Новая сборка появляется после каждого пуша.

На телефоне разрешите установку из неизвестных источников для браузера/файлового менеджера.
Все сборки подписаны одним ключом, поэтому новая версия ставится поверх старой.

## Если музыка всё равно останавливается

Некоторые прошивки (Xiaomi/MIUI, Samsung, Huawei, Honor) агрессивно экономят батарею:
Настройки → Приложения → YT Фон → Батарея → **Без ограничений**
(на Xiaomi также включите «Автозапуск»).

## Как это работает

- `BackgroundWebView` сообщает системе, что окно видимо, даже когда экран выключен,
  поэтому Chromium не ставит видео на паузу.
- Скрипт на странице подменяет `document.hidden`/`visibilityState` и глушит
  `visibilitychange`, чтобы сам YouTube не останавливал воспроизведение.
- `BlackScreen` — чёрное окно поверх всех приложений (`TYPE_APPLICATION_OVERLAY`) с
  `FLAG_KEEP_SCREEN_ON`; закрывается само, если экран выключили по-настоящему.
- `PlaybackService` — foreground-сервис типа `mediaPlayback` с wake lock и Wi-Fi lock:
  держит процесс живым и показывает медиауведомление с кнопками на экране блокировки.

## Сборка вручную

```
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Нужны JDK 17 и Android SDK 35.
